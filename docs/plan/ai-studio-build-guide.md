## 1-B. 통화 (대화용)

```
B-2를 만들어 줘. 핵심 요구사항:
- gemini-3.8-live 사용, 세션 재개(session resumption)와 컨텍스트 창 압축(sliding window)을 반드시 켜기
- GoAway 메시지를 받으면 자동 재연결, 화면에는 "연결 유지 중"만 짧게 표시
- 브라우저가 Gemini에 직접 연결하고 서버는 임시 토큰(ephemeral token)만 발급. 임시 토큰이 실패하면 서버 중계로 전환할 수 있게 구조를 나눠 둬
- 기존 server.ts의 Live 중계(/live)는 "서버 중계" 대체 경로로 재사용하고, 기존 오디오 처리(16kHz 변환, 에코 게이트, AudioSink, 말 끊기)는 그대로 유지
- 한국어 고정(ko-KR languageLock, 한국어 전사 문구)과 한국어 친구 페르소나(PersonaPrompt.ts)를 없애고 영어 튜터 기준으로 바꾸기
- 통화 시작 시 "오늘 수업 지시서"(목표, 과 내용, 복습 대상 실수 최대 3개)를 시스템 프롬프트로
- 화면 버튼: Done / Feedback / Model answer / Pause / Slow
- Live 자체 받아쓰기는 켜 두고 sessions.liveTranscript에 보조로만 저장
```

**확인**: 오늘 수업으로 통화 시작 → **15분 이상** 대화 → 중간에 끊겨도 저절로 이어지고 튜터가 앞 대화를 기억하는지.

## 1-C. 통화 중 녹음 (끊김 대비)

```
B-3을 만들어 줘.
- 마이크 소리를 10초 조각으로 녹음(MediaRecorder), 각 조각을 IndexedDB에 먼저 저장하고 바로 Cloud Storage에 업로드, 업로드 성공하면 IndexedDB에서 삭제
- Live 연결이 끊겨도 녹음은 계속
- 녹음이 1분 분량 쌓일 때마다 서버가 그 1분을 gemini-3.5-transcribe(VERBATIM)로 받아써서 sessions.sttPartial에 저장 (대화와 별도로 처리, 설정에서 끌 수 있게)
- Live 대화 로그도 통화 중 계속 저장. 세션 재개가 실패하면 그때까지의 대화 요약을 새 세션 시스템 프롬프트에 넣어 이어가기
- 마지막 조각 이후 2분 동안 새 조각이 없으면 서버가 끊긴 통화로 보고 자동 복기 시작
- 앱이 닫혔다가 다시 열리면 "끝나지 않은 통화가 있어요. 복기할까요?" 표시
- 통화 화면에 "통화 중에는 화면을 켜 두세요" 안내와 Wake Lock 요청
- sessions.recordingChunks에 조각 목록 저장
```

**확인**: 통화 3분 → 일부러 브라우저 탭 닫기 → 다시 열기 → "끝나지 않은 통화" 안내가 뜨는지. Firebase 콘솔의 Storage에 10초짜리 파일들이 쌓였는지(AI Studio에 "Storage에 저장된 파일 목록 보여 주는 관리 화면 만들어 줘"라고 해도 됨).

## 1-D. 통화 후 복기 (기록용)

```
B-4를 만들어 줘.
- 통화가 끝나면 녹음 조각을 합쳐 SttProvider로 받아쓰기. 기본은 gemini-3.5-transcribe, VERBATIM 모드(문장을 고쳐 적지 않는 모드)
- gemini-3.8-flash에 [기록용 받아쓰기 + Live 대화 로그 + 수업 지시서]를 넣어 JSON 스키마로 복기 생성
- myPhrase는 기록용 받아쓰기의 문장을 그대로 쓰고 절대 고쳐 쓰지 말 것
- usedCorrectly, repeatedMistakes 필드 포함 (B-4 참고)
- 결과 화면: 내가 한 말 → 자연스러운 표현 → 이유 표, 외울 표현 5개, AI 예상 레벨("공식 등급 아님" 문구)
- 각 실수 옆에 "이건 내가 한 말이 아니에요" 버튼
- Keep에 붙여넣을 텍스트 복사 버튼
- 실수는 mistakes 컬렉션에 stage 1, status reviewing으로 저장
```

**확인**: 일부러 틀린 문장 3개를 섞어 5분 통화 → 복기 표의 "내가 한 말"에 **틀린 그대로** 나오는지.

## 1-E. Keep 가져오기와 사용량

```
B-10을 만들어 줘.
- Keep 목록 텍스트를 붙여넣으면 gemini-3.8-flash가 [내가 한 말 / 자연스러운 표현 / 이유]로 나눠 미리보기, 확인 버튼을 누르면 mistakes에 source=keep_import, stage 1로 저장
- 통화 분, 받아쓰기 분, 토큰, TTS 글자 수, 예상 비용을 usage에 기록하고 설정 화면에 이번 달 합계 표시. 단가는 models.ts 옆 단가표 한 곳에서 관리
```

**확인**: 0-3에서 복사해 둔 Keep 텍스트 붙여넣기 → 미리보기에서 문장 수가 맞는지 → 저장 → 실수 보관함에 나오는지. 설정 화면에 오늘 통화 비용이 보이는지.
