# 시험 통화 엔진 모델 교체 비용 추정 (2026-11-27 KST)

단가 출처: https://ai.google.dev/gemini-api/docs/pricing (유료 등급, 1M 토큰당, 2026-11-27 확인). 캐시 최소 입력: https://ai.google.dev/gemini-api/docs/caching.

## 가정 (기획안 `docs/plan/google-streaming-poc-plan.md` 부록 A와 같음)
- 10분 통화, 분당 4턴(40턴), 튜터 발화 300초.
- 받아쓰기: 600초 × 25토큰/초 입력($3.50), 출력 분당 175토큰(1,750토큰, $21.00).
- 답변 입력: 40턴 × 평균 4,500토큰 = 180,000토큰. 답변 출력: 턴당 100토큰(4,000토큰).
- 새 구성만: 사고(thinking `low`) 턴당 200토큰(공식 수치 없음, 가정). 출력 단가에 사고 포함.
- 음성 입력: 답변 글 4,000토큰. 음성 출력: 300초 × 25토큰/초 = 7,500토큰.
- 기본 Live 엔진: 기획안 기준 10분 $1.50(제안서 월 $45.12 ÷ 30통). 2027년 값은 다시 추정하지 않음.

| gemini-3.1-flash-lite | $0.25 / $1.50 | 같음 |
| gemini-3.8-flash | $0.75 / $3.75 (캐시 $0.075) | $1.50 / $7.50 (캐시 $0.15) |

## 판정
- 합격선(10분 ≤ $0.30): 새 구성은 기획안 가정으로 2026년 $0.34라 **넘는다**. 2027년은 $0.59로 크게 넘는다.
- 차이는 답변 입력 단가 3배($0.25 → $0.75)와 음성 출력 1.5배($6 → $9)에서 온다.
- 3.8 Flash는 입력이 4,096토큰 이상이면 암시적 캐시가 기본으로 켜지고 적중분은 $0.075다. 입력의 약 32% 이상이 적중하면 2026년 단가로는 $0.30 안에 든다. 적중률은 문서에 없으므로 실측으로만 확인할 수 있다.
- 앱의 시험 통화 비용식은 캐시 적중을 빼지 않으므로 화면 값은 상한이다.
- 2027년 단가 전환 시점은 앱에서 KST 2027-01-01 00:00으로 계산한다. 공식 문서는 「January 1, 2027」만 적고 시간대를 밝히지 않아 경계 몇 시간은 실제 청구와 다를 수 있다.
