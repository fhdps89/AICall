## 3. 문제가 아니었던 것
- `firebase-applet-config.json`의 Firebase 웹 API 키: 원래 공개되는 값.
- `firestore.rules`: 허용 계정 1개, 본인 `users/{uid}` 아래만 읽기·쓰기 — 올바름.
- 서버 로그인 확인(`server/auth.ts`): 서명·발급자·대상·만료·이메일 확인 — 올바름.

## 4. 남은 것
- `npm audit` high 4건: Firebase가 쓰는 `@grpc/grpc-js`에서 나옴. 브라우저 앱에서는 쓰이지 않는 부분으로 추정. 고치려면 Firebase 큰 버전 업그레이드가 필요해 보류.
- v2.8.0 전에 승인한 코치 변경을 되돌리면, 바꾼 항목은 예전 방식으로 기록된(더 오래된) 값으로 돌아갈 수 있음.
- 실제 앱 통화(로그인·마이크·Gemini 키 필요)로는 재현하지 않았음. 배포 후 확인할 것:
  1. 통화를 끝내고 복기를 닫았을 때 "오늘 수업"이 다음 과로 바뀌는지
  2. 새로고침 없이 두 번째 통화에서 튜터가 새 과로 인사하는지
  3. 코치 창을 닫았다 열어도 코치 답장이 남는지
  4. 오인식 신고 후 오늘 퀴즈 개수가 줄어드는지
  5. 아이폰에서 퀴즈 말하기가 인식되는지
